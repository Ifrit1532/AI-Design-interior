# 🏠 Рено — AI Редизайн Интерьера

Веб-приложение для AI-редизайна интерьеров и автоматической генерации сметы ремонта.

## Возможности

- **Редизайн изображения** — точечное изменение элементов интерьера с сохранением геометрии, планировки, окон, дверей через OpenAI `gpt-image-1`
- **Смета ремонта** — детальная смета с расценками по категориям (работы + материалы) через Anthropic Claude
- **Сравнение «До / После»** — удобный просмотр изменений
- **Экспорт** — скачать изображение, выгрузить смету в CSV, распечатать

## Стек

| Часть       | Технология                         |
|-------------|-------------------------------------|
| Frontend    | Vanilla JS SPA (без фреймворков)    |
| Backend     | Node.js + Express + Multer          |
| Редизайн    | OpenAI API — `gpt-image-1` (edit)   |
| Смета       | Anthropic API — `claude-sonnet-4-20250514`  |

## Быстрый старт

### 1. Клонируйте / распакуйте проект

```bash
cd interior-redesign
```

### 2. Установите зависимости

```bash
npm install
```

### 3. Создайте файл `.env`

```bash
cp .env.example .env
```

Откройте `.env` и вставьте ваши API-ключи:

```env
OPENAI_API_KEY=sk-...          # ключ OpenAI (нужен для редизайна)
ANTHROPIC_API_KEY=sk-ant-...   # ключ Anthropic (нужен для сметы)
PORT=3000
```

### 4. Запустите сервер

```bash
# Продакшн
npm start

# Разработка (с автоперезагрузкой)
npm run dev
```

### 5. Откройте в браузере

```
http://localhost:3000
```

### Маршруты API

| Метод | Путь              | Описание                          |
|-------|-------------------|-----------------------------------|
| GET   | `/api/health`     | Статус подключения к AI-сервисам  |
| POST  | `/api/redesign`   | Редизайн изображения (multipart)  |
| POST  | `/api/estimate`   | Генерация сметы (JSON + base64)   |

### `POST /api/redesign`

**Тип запроса:** `multipart/form-data`

| Поле          | Тип    | Описание                          |
|---------------|--------|-----------------------------------|
| `image`       | File   | Фото интерьера (JPG/PNG, до 20MB) |
| `description` | string | Описание желаемых изменений       |

**Ответ:**
```json
{
  "success": true,
  "image": "data:image/png;base64,...",
  "revised_prompt": "Интерпретация запроса моделью"
}
```

### `POST /api/estimate`

**Тип запроса:** `application/json`

| Поле           | Тип     | Описание                                  |
|----------------|---------|-------------------------------------------|
| `imageBase64`  | string  | Data URL изображения (исходного или AI)   |
| `description`  | string  | Описание изменений (опционально)          |
| `isRedesigned` | boolean | Флаг: передаётся отредактированное фото   |

**Ответ:**
```json
{
  "success": true,
  "estimate": {
    "summary": "...",
    "area_sqm": 25,
    "categories": [...],
    "total_works": 150000,
    "total_materials": 280000,
    "grand_total": 430000,
    "timeline_weeks": 6,
    "notes": [...]
  }
}
```

## Примечания

- Цены в смете ориентированы на **Москву 2024–2025**
- Для редизайна используется модель `gpt-image-1` с инструкцией сохранять геометрию помещения
- Максимальный размер загружаемого изображения — **20 МБ**
- Время генерации редизайна: **20–60 секунд**
